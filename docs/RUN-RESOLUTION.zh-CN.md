| 操作 | 行为 | 原记录和计数 |
| --- | --- | --- |

有同任务排队或运行时，禁止确认和关联重试，防止覆盖在途结果或重复派发。已删除任务无法跳转，运行记录保留确认无误及重新添加入口。取消“标记已处理 / 忽略提醒”；异常只按真实运行状态判定，旧的已读或忽略标记不再隐藏异常。确认或重试成功后恢复正常交互，重试失败继续保留异常。

## 兼容和恢复

- 存储仍为 version 1、definitions / runs 两张表，只增加可选 retryOfRunId、retryScheduledFor、resolution 字段。原错误保存在 resolution 审计中。
- 新 Host 显式提供 runResolutionSupported 和 needsAttention；新 Client 对旧 Host 保留原接口并隐藏不支持的新处理按钮。
- 原 mark-read 接口保留兼容旧调用，但已读和 reviewedAt 标记均不再消除异常；新 read-run 仅清已读。读取会话期间运行完成时会重新读取最新状态，避免旧快照覆盖成功结果。
- 成功重试的父记录更新若中断，启动时幂等补齐，不重新执行任务。未处理的重试父记录在普通历史裁剪中保留；其他历史仍受原保留策略限制。
- 普通重试不替代下一计划；若原失败记录本来就是提前执行，处理成功仍承接原记录已指定的替代时点，其余后续计划保留。
- 不自动将已有误报标成成功。用户需要打开会话核对，再选择确认无误；未完成的任务选择重试。
