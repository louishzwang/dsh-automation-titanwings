# 自动化插件优化与交接（2026-09-06）

本轮基线为 `5a833e5`，工作分支为 `fix/automation-reliability-performance`。修改均为本地提交；没有推送远程，也没有新建或更新 PR。已有 PR #20 / #21 的分支未改动。

## 完成的修改

1. **历史删除与防重复执行**：删除和保留期限裁剪运行记录前，先在对应定义中保存最小执行凭据；写入凭据失败时保留原记录。删除记录继续保留会话，不隐式重新运行任务。
2. **提前执行**：手动执行与 Host 快照共用“下一个尚未完成的计划”计算。连续提前执行按界面显示的下次计划推进；失败、取消不产生替代凭据。
3. **补跑边界**：等待窗口包含恰好位于边界上的任务；0 分钟下过期任务产生 missed/skipped 记录；策略保存完成后重新唤醒调度器。过期记录仍受保留期限约束。
4. **补跑效率**：从最近的到期点向前取足补跑上限，不先枚举全部历史。返回顺序保持旧到新，interval 仍沿用原来的 grace/skip 路径。
5. **历史快照**：一次按任务分组复用。普通最近 N 条之外，运行中、排队中和仍未处理的问题记录保持可见；Host 下发整个工作区当前保留记录中的 attentionCount。
6. **时区与草稿**：缓存时区选项，避免每次输入重建数百个 Intl 格式化器；草稿写入合并为 250ms，关闭或 pagehide 时保存最新草稿，放弃或成功提交后不恢复已清除的草稿。存储拒绝时不显示虚假的“已保存”。
7. **前端容错**：视图偏好读取失败回退周视图；模型目录逐项检查，保留合法供应商和模型，异常条目以目录错误提示，并保留原有已保存路由的 unavailable 回退。
8. **提交结果**：Host 确认操作成功后，刷新失败只显示“操作已完成，但列表刷新失败”；不把成功操作当作失败，也不自动重发写入。
9. **前端生命周期**：轮询在请求结束后安排下一次，失败 3 秒重试、成功 15 秒；隐藏页面暂停读取、恢复可见立即刷新。侧栏 DOM 更新按动画帧合并，并过滤会话流式更新；无订阅的会话释放较大的快照数据，保留稳定的运行时身份。

## 兼容性约束

- 包名、版本号、exports、Cordis patch、Host/Web bundle 格式保持原状；没有新增或升级运行时依赖。
- React/ReactDOM 继续由宿主提供；保留 body portal、视口约束、无滚动聚焦和 `ctx.remote.session.modelCatalog()`。
- 权限仍为 read-only / workspace-write；fresh Agent、审批策略 never、工具白名单、loopback RPC 和工作区归属检查保持原状。
- 存储 domain 版本仍为 1，表仍为 definitions / runs。定义只增加可选字段：
  - `scheduleHandledThrough`：从被删除/裁剪的定时记录中保留的处理进度；
  - `retiredReplacements`：成功提前执行、但原记录已删除/裁剪的计划时点。已被处理进度覆盖的时点会合并移除。
- 普通编辑保留这些可选字段。写检查点不增加定义 revision，也不修改 updatedAt。旧数据无字段时仍可读取，无启动批量迁移。
- `attentionCount` 是可选 wire 字段；新客户端连接旧 Host 时仍回退到已有的列表统计。旧客户端可继续消费原有字段。
- 用户手动执行仍允许产生新运行；防重只针对同一个已处理的定时计划，不将手动操作变成自动重试。
- 已经在本轮前被删除的历史无法凭空恢复防重信息。本轮没有读取或修改真实任务存储。
- 回退旧代码可读 version-one 数据，但旧实现会忽略新增检查点，且本身没有修复防重问题；不能承诺回退后仍具备新的防重行为。需要回退时，先在宿主停止后备份实际存储，并暂停相关任务核查，避免旧实现重新派发。

## 同进程对照测量

环境：本机 Node.js v26.7.0，内存中的模拟数据；旧实现直接读取 Git 基线 `5a833e5`。每组 5 次，下面采用中位数；时区缓存热调用排除第一次初始化。

| 场景 | 基线 | 优化后 |
| --- | ---: | ---: |
| 70 条任务、14,000 条运行记录的快照 | 66.992 ms | 52.016 ms |

## 生效与验收

Desktop profile 使用指向本地仓库的链接，宿主加载 `lib/`。本轮同时包含 Host 和 Client 修改，需要在方便时完整重启 DSH Desktop，使两端一起加载本轮产物。

建议在专用测试工作区，用无写入副作用的提示验证：

1. 新建/编辑窗口正常；模型和推理强度可选；浅色/深色、窄窗口、拖动缩放正常。
2. 连续输入长提示词不卡顿；立即关闭保留草稿；放弃草稿、创建成功后刷新不恢复旧草稿。
3. 一次性任务成功后删除运行记录，再重启/刷新调度，不再次自动运行；原会话保留。
4. 同一 daily 任务连续提前执行，第二次替代时间与弹窗一致；失败时计划不被消耗。
5. 保存补跑策略立即重新评估；到期边界和错过记录符合设置。
6. 超过普通历史显示数量后，仍能看到运行中及未处理问题；处理后计数下降。
7. 切换会话、隐藏/恢复页面后正常恢复，且无重复轮询或侧栏重复入口。
8. 失败、取消、中断和运行中的任务按原计划日期出现在周/月视图；“需关注”和“运行中”计数与日期卡片一致，打开会话后再决定是否重试。
